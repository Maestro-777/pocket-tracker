# Pocket Tracker v3

## Установка
Загрузи эту папку через \`edge://extensions\` / \`chrome://extensions\` → Режим разработчика → Загрузить распакованное расширение.

После установки перезагрузи торговую вкладку Pocket Option, чтобы MAIN-world перехватчик установился до создания WebSocket.

## Использование
Расширение не просит SSID/UID и не подключается к Pobot. Оно работает поверх уже открытой и авторизованной вкладки Pocket Option.

Переключи терминал на DEMO, открой popup, дождись подтверждения DEMO, затем нажми «Подключить текущий актив». Поиск сигналов и автоторговля включаются отдельно; автоторговля выключена по умолчанию.

## Стратегия
5-секундные закрытые свечи, BB(20,2), RSI Wilder(14), PUT 77–83 у верхней полосы, CALL 18–23 у нижней, экспирация 15 секунд. Интервал свечи и экспирация независимы.

## Безопасность
Для торговли требуются DEMO endpoint и серверное \`isDemo=true\`. REAL или неизвестный счёт не допускается. Если ответ на заявку не пришёл за 12 секунд, повтор заблокирован. Сессионные токены не считываются для передачи и не сохраняются.

Поддерживаемые домены: \`pocketoption.com\`, поддомены \`pocketoption.com\`, \`p.finance\`.
