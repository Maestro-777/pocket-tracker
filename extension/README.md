# Pocket Tracker — Signal Bridge

Расширение Manifest V3. Версия 1.2 добавляет read-only перехват рыночных событий непосредственно в контексте открытой страницы Pocket Option.

## Обновление

1. Открой `chrome://extensions` или `edge://extensions`.
2. Включи режим разработчика.
3. Нажми «Обновить» у расширения либо удали старую распакованную версию и заново загрузи папку `extension`.
4. Полностью перезагрузи вкладку Pocket Option (Ctrl+Shift+R), чтобы скрипт `page-hook.js` установился до создания WebSocket.
5. Открой popup расширения и нажми «Обновить состояние».

## Прямое получение данных

- `page-hook.js` устанавливается в MAIN world на страницах Pocket Option и наблюдает WebSocket сообщения страницы.
- Для распознавания типа счёта читается только поле `isDemo` из исходящего Socket.IO auth frame. Session, uid и прочие поля авторизации не передаются в расширение и не сохраняются.
- Перехватываются события `successauth`, `loadHistoryPeriodFast`, `updateStream`, `updateAssets`.
- `content.js` передаёт состояние и рыночные события в background; popup показывает статус подключения и тип счёта.
- Рыночные данные не отправляются на локальный Pocket Tracker и не требуют его для подключения к Pocket Option.

## DEMO-only и блокировка торговли

Текущая версия — только наблюдение. Любое исполнение ордеров отключено независимо от типа счёта. Неопределённый тип счёта и REAL считаются запрещёнными состояниями (fail-closed). Отображение DEMO не означает, что торговый протокол уже подтверждён.

Ручные BUY/SELL и автоматическая торговля пока не активны: внутренний протокол открытия сделки и получения окончательного результата не подтверждён. Никакие клики по кнопкам сайта, сообщения о сигнале или тестовые уведомления не считаются сделками.

## Статистика

Popup показывает нулевые счётчики до тех пор, пока не будет добавлен и проверен источник подтверждённых результатов сделок. Сигналы, тики и уведомления не засчитываются как победы или поражения. В этой версии не создаются фиктивные записи сделок.

## Важно

Pocket Option может изменить внутренний Socket.IO протокол. Расширение не подменяет сообщения страницы и не отправляет брокеру торговые команды. Текущая версия не открывает сделки, в том числе на DEMO.
