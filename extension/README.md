# Extension files

Загружай в Chrome/Edge именно эту папку через «Загрузить распакованное расширение».

Перед подключением:
1. Открой Pocket Option и вручную переключи аккаунт на DEMO.
2. В окне Pocket Tracker вставь полную строку Socket.IO auth, начиная с `42["auth",...`.
3. Выбери торговый символ.
4. Нажми «Подключиться к DEMO».
5. Дождись статуса «DEMO подтверждён».

Токен из auth-сообщения не сохраняется на диск и не попадает в логи. Расширение не использует chrome.debugger и не перехватывает страницу Pocket Option.

Автоматическая торговля включается отдельным переключателем и только после серверного подтверждения DEMO. Сначала накопи историю свечей и проверь получение сигналов, затем тестируй ручные сделки на DEMO.

Таймфрейм стратегии 5 секунд, экспирация 15 секунд. Сигналы рассчитываются по закрытым свечам BB(20,2) + Wilder RSI(14).
