PocketOption Signal для Windows

Приложение для Windows подключено. Чтобы бот появлялся на зеркалах Pocket Option, разрешите расширению работать на всех сайтах. Оверлей включается только когда переключатель в приложении стоит в положении ВКЛ.

Пока лицензия активна, расширение раз в минуту передаёт на pocketoption-signal.online открытые пары, тип счёта (демо/реальный) и результаты сделок. Firefox спросит об этом отдельно; без согласия бот работает, статистика не отправляется.
