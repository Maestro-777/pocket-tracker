# Pocket Pattern Lab — research build 0.2.0

Отдельная версия расширения. Установка: Chrome → Extensions → Developer mode → Load unpacked → выбрать папку `pattern-lab/`.

## Что реализовано
- MAIN-world наблюдатель за WebSocket-событиями открытой вкладки Pocket Option.
- Извлечение событий каталога, потока котировок и истории из текстовых Socket.IO-пакетов.
- Приём тиков и построение локальных 5-секундных OHLC-свечей.
- Приём исторических свечей только когда OHLC-поля можно распознать; price-only историю расширение не выдаёт за OHLC.
- Локальное хранение свечей в IndexedDB, дедупликация по инструменту/периоду/времени.
- Отображение состояния соединения и числа сохранённых свечей в popup.
- Анализ локальной live-базы и CSV в paper/research режиме.

## Ограничения этой сборки
- Наблюдатель только читает уже открытое соединение. Он не отправляет запросы истории и не переключает активы.
- Нет подтверждённого способа загрузить сразу 10 000 свечей на каждый актив. Текущая база растёт с момента установки и получает только те исторические данные/тики, которые сайт сам передал после подключения наблюдателя.
- Событие каталога пока используется только для диагностики количества записей. Выбор 10 OTC пар и фильтр payout ≥90% ещё не реализованы.
- Текстовые Socket.IO события обрабатываются; бинарные attachment-пакеты намеренно не декодируются до проверки их framing на реальном capture.
- Нет автоторговли, отправки ордеров или имитации кликов. Версия остаётся read-only/paper-only.

## Проверка
1. Перезагрузить расширение на странице Chrome Extensions.
2. Полностью обновить вкладку Pocket Option (скрипт должен загрузиться до WebSocket-соединения).
3. Оставить график открытым и подождать поступления тиков.
4. Открыть popup → проверить статус соединения и счётчики → нажать «Анализировать live-базу».

Если соединение не определяется, сохранить диагностические сведения из popup и консоли страницы. Не включать торговлю на этой сборке.

## Методика
Сходство ≥80% — это только порог похожести формы, а не вероятность выигрыша. Для торговых выводов нужны независимые завершённые исходы, walk-forward проверка, достаточная выборка, фактическая выплата, ничьи и задержки исполнения.
