# Pocket Pattern Lab — research build 0.1.0

Новая отдельная папка расширения. Установка: Chrome → Extensions → Developer mode → Load unpacked → выбрать `pattern-lab/`.

## Что уже реализовано
- Heikin Ashi преобразование из OHLC.
- Сравнение последовательностей: цвет/направление, тело, верхняя/нижняя тень, диапазон свечи.
- Поиск похожих окон в истории.
- Проверка только завершённых исторических исходов, без использования будущих свечей при выборе аналога.
- Выбор лучшего горизонта экспирации по истории.
- Минимальное число аналогов, порог сходства, длина паттерна, payout threshold, paper mode.
- CSV импорт и экспорт отчёта; локальное хранение настроек.

CSV формат: `time,open,high,low,close,volume`. Временной интервал должен быть 5 секунд. Пока анализируется один импортированный инструмент за раз.

## Что намеренно не включено
Нет подключения к внутреннему потоку Pocket Option, автоматического определения OTC/payout, многопарного сканирования и отправки реальных ордеров. В репозитории пока нет подтверждённой спецификации актуального потока котировок/истории и безопасного торгового интерфейса. Угадывать внутренний протокол или эмулировать нажатия CALL/PUT рискованно: можно перепутать актив, сумму, счёт или экспирацию. Поэтому этот билд — research/paper-only; он не торгует.

## Важная методика
Порог сходства (геометрическая близость) не является win rate. Win rate рассчитывается отдельно по исходам после исторических аналогов. Перед использованием необходим walk-forward тест на свежих данных, проверка payout/OTC и учёт ничьих, задержек, проскальзывания и выплат брокера. Результаты не гарантируют доходность.
