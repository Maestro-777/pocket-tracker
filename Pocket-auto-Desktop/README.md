# Pocket Tracker Desktop — фоновая диагностика и статистика

Отдельная тестовая сборка Electron. Исходная папка `Pocket-auto` не изменяется.

## Возможности

- Постоянный Chromium-профиль Pocket Option: `persist:pocket-tracker-desktop`.
- DEMO: `/ru/cabinet/demo-quick-high-low/`; REAL: `/ru/cabinet/quick-high-low/RUB/`.
- Переключение DEMO/REAL из панели; открытие REAL требует подтверждения.
- Локальная копия расширения с торговым ядром Pocket Tracker.
- Фоновый JavaScript таймер и ручной тест скрытого окна на 30 секунд.
- Автоматическая диагностика каждые 5 минут: таймер, WebSocket, свежесть котировок, наличие ядра, состояние сканера и динамика количества циклов сканирования.
- Автоматическое сохранение событий сигналов и результатов сделок.
- На каждый снимок анализа и каждый сигнал записываются выбранные индикаторы, фактически применённые периоды/пороги, режим фильтра, подтверждение, экспирация, таймфрейм, параметры профиля и состояние свечей/тиков/HTF.
- Автовосстановление после сетевого обрыва: если сеть вернулась, но соединение не восстановилось в течение 90 секунд, приложение может перезагрузить торговую страницу (не более трёх попыток).
- Автовосстановление не перезагружает страницу, пока ядро запущено, активна автоторговля или выполняется сделка. В этом состоянии приложение только записывает предупреждение, чтобы не прерывать торговую сессию.
- При штатном выходе анализатор останавливается, данные статистики дозаписываются, постоянный профиль Chromium синхронизируется.
- `run-watchdog.bat` запускает Electron под watchdog-процессом и повторяет запуск после аварийного завершения (до пяти попыток).

## Запуск

Требуется Node.js 24 и npm.

Обычный запуск:

```bat
npm install
npm start
```

Запуск с автоматическим восстановлением Electron после аварийного завершения:

```bat
run-watchdog.bat
```

При нормальном закрытии приложения watchdog завершает работу. При неожиданном ненулевом коде выхода он повторит запуск с возрастающей задержкой.

## Автоматическая диагностика

После старта выполняется первая проверка через 20 секунд, далее — каждые 5 минут. Проверка не скрывает окно, не нажимает торговые кнопки и не запускает сделки.

Проверяются:
- жизнь фонового контрольного таймера и число тиков за интервал;
- наличие WebSocket и возраст последней котировки;
- загрузка `QuotexCore`;
- работает ли сканер и сколько циклов анализа было выполнено;
- сколько сигналов и торговых результатов зарегистрировано.

Если сканер выключен в интерфейсе расширения, приложение покажет это как ожидание, а не будет запускать его самостоятельно. Для накопления статистики поиска сигналов запусти анализатор из панели Pocket Tracker; автоматическую торговлю для этого включать не требуется.

## Файлы статистики

В панели нажми **«Открыть папку статистики»**. Путь также показывается в панели и журнале.

Приложение пишет файлы JSON Lines (`.jsonl`) по датам:

- `health-YYYY-MM-DD.jsonl` — проверка устойчивости каждые 5 минут;
- `scans-YYYY-MM-DD.jsonl` — агрегированные сведения об анализе, последнем состоянии фильтров и параметрах ядра;
- `signals-YYYY-MM-DD.jsonl` — сигналы и точные параметры, использованные при их формировании;
- `trades-YYYY-MM-DD.jsonl` — события открытия/результатов сделок.

Каждая строка — отдельный JSON-объект. Файлы можно открыть редактором кода или обработать Python/Excel.

## Авторизация и завершение работы

Сессия хранится в persistent-разделе Electron. Приложение не очищает cookies, localStorage или профиль Pocket Option. При выходе выполняется `flushStorageData()`. Кнопка «Перезапустить Electron» выполняет штатное завершение и повторный запуск, но блокирует перезапуск, если включена автоторговля.

## Ограничения и безопасность

- Прототип не гарантирует непрерывную работу при сне/выключении Windows, сбое питания или проблеме на стороне Pocket Option.
- Сетевое восстановление не вмешивается в работающий сканер/автоторговлю; в таком случае требуется ручное решение.
- Watchdog перезапускает процесс Electron при аварийном завершении, но не имитирует тест отключения питания и не гарантирует восстановление серверной сделки.
- Сбор статистики зависит от того, что торговое ядро получает котировки и выполняет сканирование. Если анализатор выключен в интерфейсе, записи сигналов не появляются.
- Автоматические проверки не запускают сделки и не включают автоторговлю.
- Все испытания сначала выполняй на DEMO. REAL оставляй выключенным до отдельной проверки.
