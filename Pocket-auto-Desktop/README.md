# Pocket Tracker Desktop — первый этап

Это отдельная тестовая сборка Electron. Она не меняет исходную папку `Pocket-auto`.

## Что реализовано

- Electron-приложение с отдельной панелью состояния.
- Постоянный профиль Chromium: авторизация Pocket Option сохраняется между запусками.
- Загрузка локальной копии расширения при каждом старте приложения.
- Исходные `inject.js`, `content.js`, `account-mode.js` и CSS берутся из Pocket-auto 4.0.
- Поддержка DEMO/REAL-детектора и исходного торгового ядра.
- Минимальный Electron-совместимый background-адаптер вместо старого Windows bridge и телеметрии.
- Контрольный JavaScript-таймер в главном фрейме сайта.
- `backgroundThrottling: false` для окна Pocket Option.
- Тест на 30 секунд: скрывает окно сайта и проверяет, что таймер продолжает выполняться.

## Запуск на Windows

Требуется Node.js 24 LTS или совместимая версия npm.

1. Скачайте репозиторий с ветки `feature/pocket-desktop-background`.
2. Откройте терминал в папке `Pocket-auto-Desktop`.
3. Выполните:

```bash
npm install
npm start
```

4. Дождитесь загрузки Pocket Option и войдите в свой аккаунт вручную.
5. Убедитесь, что в панели обнаружены расширение и торговое ядро.
6. Сначала проверьте распознавание DEMO-счёта.
7. Нажмите «Запустить тест 30 секунд». Окно Pocket Option будет скрыто, а панель продолжит показывать состояние.
8. После теста откройте сайт кнопкой «Показать Pocket Option».

## Важные ограничения первого этапа

- Это прототип соединения и фонового выполнения, а не готовый автономный торговый терминал.
- Автоматический старт торговли не выполняется.
- Для проверки сначала используйте только DEMO и не включайте REAL.
- Фоновый тест доказывает работу контрольного JavaScript-таймера. Отдельно нужно подтвердить, что внутренний WebSocket Pocket Option остаётся подключённым и что само торговое ядро корректно работает при скрытом окне.
- Сон Windows, выключение компьютера, потеря сети, закрытие приложения или выход из аккаунта прерывают работу.
- Electron поддерживает не все Chrome Extensions API. Поэтому в этой сборке заменён background-скрипт, а не используется старый bridge/telemetry-код.
- Electron не гарантирует совместимость с любыми изменениями DOM или внутреннего протокола Pocket Option.

## Данные и профиль

Профиль Chromium хранится в системной папке приложения Electron в разделе `userData`, в отдельной постоянной сессии `persist:pocket-tracker-desktop`.

Лог приложения записывается в `logs/desktop.log` внутри `userData`.

Исходная папка `Pocket-auto` остаётся без изменений.
