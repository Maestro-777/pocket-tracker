# Pocket TRADE ROBOT — Expansion (персональная автономная сборка)

Эта папка — отдельная копия расширения на основе исходной версии `2.0.50_0`. Исходная папка не изменялась.

## Локальный режим

- Отдельная система пользователей, регистрация, вход и роли отсутствуют: сборка предназначена для одного владельца.
- Premium-статус и локальные функции доступны без прежнего лицензионного сервера.
- Разрешение на торговую операцию и одноразовый execution ticket обрабатываются локально.
- Пользовательские стратегии и отчёты сделок сохраняются в профиле Chrome.
- Старый API/лицензионный сервер, удалённая админка, партнёрские API и Remote Control отключены.
- Схема состояния торгового ядра — версия 2; версия сборки интерфейса, service worker и ядра синхронизирована.

## Установка или обновление

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Если старая копия уже установлена, нажмите «Обновить» (или удалите старую распакованную копию и загрузите эту папку заново).
4. Нажмите «Загрузить распакованное расширение» и выберите папку `expansion`.
5. Перезагрузите вкладку Pocket Option.

При обновлении сохранённые стратегии и настройки не удаляются. Старые ключи локальной системы пользователей очищаются при запуске новой версии.

## Что пока не перенесено

Автономность не означает, что браузерный терминал Pocket Option или его рыночные данные становятся локальными. Для работы нужен сам сайт Pocket Option.

Следующие серверные функции старой версии требуют отдельной реализации и пока отключены:
- внешний WebSocket-канал сигналов;
- Remote Control с телефона;
- реферальные и партнёрские API;
- автообновления с прежнего домена.

Встроенные торговые функции необходимо сначала проверить на DEMO. Реальная торговля несёт риск потери средств.
