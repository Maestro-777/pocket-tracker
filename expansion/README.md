# Pocket TRADE ROBOT — Expansion (персональная автономная сборка)

Эта папка — отдельная копия расширения на основе исходной версии `2.0.50_0`. Исходная папка не изменялась.

## Локальный режим

- Отдельная система пользователей, регистрация, вход и роли отсутствуют: сборка предназначена для одного владельца.
- Premium-статус и локальные функции доступны без прежнего лицензионного сервера.
- Разрешение на торговую операцию и одноразовый execution ticket обрабатываются локально.
- Пользовательские стратегии и отчёты сделок сохраняются в профиле Chrome.
- Старый API/лицензионный сервер, удалённая админка, партнёрские API и Remote Control отключены.
- Схема состояния торгового ядра — версия 2; версия сборки интерфейса, service worker и ядра синхронизирована (сборка 1.0.3).

## Локальный Strategy Tester

- Движок работает на локально собранной истории свечей и не вызывает прежний сервер.
- В сборке 1.0.3 исправлен локальный путь автоторговли: для 3-Candle EMA14 используется анализ свечей в content script без серверного WebSocket; локальный режим явно восстанавливается после перезапуска service worker.
- Автоторговля в автономной версии допускает только стратегии с реально перенесённым локальным алгоритмом 3-Candle EMA14. Если выбраны серверные стратегии, запуск блокируется с понятным сообщением — фиктивные сигналы не создаются.
- Локальные execution tickets проверяют UID подключённого аккаунта, параметры сделки и срок действия; выдача/потребление сериализованы, повторное потребление блокируется. При смене UID старый билет недействителен.
- В сборке 1.0.2 реализован проверяемый OHLC-бэктест для пользовательских стратегий семейства 3-Candle EMA14.
- Сигнал рассчитывается только по закрытым свечам: сборщик исключает формирующуюся свечу по времени брокера, проверяет корректность OHLC и отбрасывает разрывы/скачки истории так же, как live-движок; вход моделируется по открытию следующей свечи, исход — по закрытию свечи на выбранной экспирации.
- Выплата (payout) берётся из снимка рынка на момент сбора истории, а не из исторического архива. Поэтому Win Rate основан на OHLC, а PnL — оценка по текущей выплате; исторические изменения payout, спред, проскальзывание и задержку исполнения тестер не моделирует.
- Для корректного расчёта экспирация должна быть кратна таймфрейму истории. Комбинации без достаточной истории или с неизвестной выплатой при заданном минимуме пропускаются.
- Остальные серверные стратегии (Trend Fusion, SmartFlow, Liquidity Sniper, Impulse Breakout, Heiken Ashi, Pattern Pulse и AI) пока не имеют перенесённых локальных алгоритмов и поэтому недоступны в локальном тестере. Они не заменяются приблизительными сигналами.

## Установка или обновление

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Если старая копия уже установлена, нажмите «Обновить» (или удалите старую распакованную копию и загрузите эту папку заново).
4. Нажмите «Загрузить распакованное расширение» и выберите папку `expansion`.
5. Перезагрузите вкладку Pocket Option.

При обновлении сохранённые стратегии и настройки не удаляются. Старые ключи локальной системы пользователей очищаются при запуске новой версии.

## Что пока не перенесено

Автономность не означает, что браузерный терминал Pocket Option или его рыночные данные становятся локальными. Для работы нужен сам сайт Pocket Option.

Следующие серверные функции старой версии требуют отдельной реализации и пока отключены:
- серверные стратегии и внешний WebSocket-канал сигналов (локальная 3-Candle EMA14 работает напрямую по свечам терминала);
- Remote Control с телефона;
- реферальные и партнёрские API;
- автообновления с прежнего домена.

Встроенные торговые функции необходимо сначала проверить на DEMO. Реальная торговля несёт риск потери средств.
