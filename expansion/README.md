# Pocket TRADE ROBOT — Expansion (локальная автономная ветка)

Эта папка — отдельная копия расширения на основе исходной версии `2.0.50_0`. Исходная папка не изменялась.

## Что уже переведено в локальный режим

- Локальные учётные записи в `chrome.storage.local`.
- Первый созданный пользователь получает роль `owner`.
- Роли: `owner` (полный доступ), `trader` (торговля и изменение стратегий), `viewer` (просмотр).
- Пароли хранятся как PBKDF2-HMAC-SHA256 хеши с индивидуальной солью; открытые пароли не сохраняются.
- Сессия локального пользователя действует 7 дней.
- Локальная проверка разрешения на сделку и одноразовые execution tickets.
- Пользовательские стратегии и отчёты сделок сохраняются локально.
- Старый API/лицензионный сервер, Premium heartbeat/bootstrap, удалённая админка и Remote Control отключены.

## Установка для разработки

1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку `expansion`.
5. Нажмите иконку расширения, создайте первого пользователя — он станет владельцем.
6. Откройте Pocket Option и проверьте соединение с терминалом.

## Ограничения текущей автономной сборки

Автономность не означает, что браузерный терминал Pocket Option или его рыночные данные становятся локальными. Для работы нужен сам сайт Pocket Option.

Следующие функции исходной версии были серверными и не могут быть честно объявлены локальными без переноса/переписывания их вычислительной или серверной части:
- внешний WebSocket-канал сигналов;
- Strategy Tester PRO (серверный расчёт);
- Remote Control с телефона;
- реферальные и партнёрские API;
- автообновления с прежнего домена.

В этой сборке они отключены, чтобы расширение не обращалось к потерянным серверам и не зависело от старых токенов. Торговые стратегии, встроенные в исходное расширение, требуют отдельного тестирования в терминале после установки. Реальная торговля несёт риск потери средств; сначала тестируйте на DEMO.

## Безопасность

Учётные записи хранятся в профиле Chrome на этом устройстве. Это локальная модель доступа, а не защищённая серверная идентификация: очистка данных расширения удалит пользователей. Не используйте один и тот же профиль Chrome совместно с недоверенными лицами.
