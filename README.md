# Pocket Tracker

Самостоятельное расширение Chrome / Edge для Pocket Option. Новая версия **v1.0.1** находится только в папке `extension/`.

> **Важно:** загружайте в Chrome/Edge только папку `extension/`. Папки `1.1.7_0/` и `3.6.0_0/` — архивные исходники, не готовая версия для установки. Старая `1.1.7_0/` содержит Pobot-проверку `api.pobot.net/user/capabilities/` и ссылку `https://api.pobot.net/register`; из новой `extension/` эти проверки, регистрация и внешняя активация удалены. Не держите старые версии включёнными одновременно с новой.

## Установка

1. Откройте Code → Download ZIP и распакуйте репозиторий.
2. Перейдите на chrome://extensions или edge://extensions.
3. Включите режим разработчика.
4. Нажмите «Загрузить распакованное расширение» и выберите папку extension.
5. Обновите вкладку Pocket Option.

## Возможности v1.0.1

В интерфейсе собраны 12 локальных сигналов/фильтров, режимы ALL / ANY / CONTEXT, встроенные пресеты, девять систем управления ставкой, Take Profit / Take Loss, журнал, статистика, экспорт CSV и графический оверлей. Таймфрейм анализа по умолчанию — 5 секунд; экспирация настраивается независимо.

Расширение запрашивает историю до 30 дней и хранит до 530 000 OHLC-свечей на инструмент. Для оперативного анализа используется отдельное окно последних 600 свечей, чтобы не сортировать месячную историю на каждом цикле.

## Защита и приватность

Автоматические сделки разрешаются только при совместном подтверждении DEMO endpoint, свежего серверного is_demo=true и активного DEMO-счёта в интерфейсе. Если любой из признаков неизвестен или не совпадает, автоматическая заявка блокируется. REAL не является резервным режимом.

Новая папка extension/ не содержит Pobot API, лицензионных проверок, Windows-моста, внешнего marketplace или телеметрии. Баланс, сделки, настройки и журнал остаются локально.

## Не вошло в первую версию

Многопарный сканер, фильтры Pobot по выплате/OTC, отслеживание продолжения мартингейла после ручных сделок, внешний маркет пресетов, Windows-мост и полный каталог из 98 индикаторов OTCharts пока не перенесены.

## Ограничения

Pocket Option использует внутренний WebSocket-протокол, который может измениться. Запрос месячной истории не гарантирует, что брокер вернёт полный период. Данные хранятся в памяти текущей вкладки и загружаются повторно после её перезагрузки.

Перед включением автоторговли проверьте подключение, 5-секундные свечи, статус DEMO и сигналы. Затем вручную проверьте сделку на DEMO. Синтаксическая проверка не заменяет тест в реальном терминале.


## Pocket Pattern Lab (новая отдельная разработка)

Исследовательская версия находится в `pattern-lab/`. Это отдельное расширение, не заменяющее существующие версии. Оно включает Heikin Ashi-преобразование, сравнение свечных паттернов, CSV-импорт OHLC, подбор исторического горизонта и независимую статистику исходов. Установка: загрузить распакованную папку `pattern-lab/` через chrome://extensions.

**Статус 0.1.0: research-only.** Многопарный OTC-сканер, реальный поток свечей и исполнение сделок ещё не подключены. До выяснения актуального формата данных и безопасного API платформы автоматическая отправка ордеров намеренно отключена. Подробности — в `pattern-lab/README.md`.
