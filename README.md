# Pocket Tracker v2

Чистая реализация расширения Chrome/Edge для мониторинга сигналов Pocket Option и торговли на DEMO.

## Установка

1. Скачай репозиторий через **Code → Download ZIP** и распакуй.
2. Открой `chrome://extensions` или `edge://extensions`.
3. Включи **Режим разработчика**.
4. Нажми **Загрузить распакованное расширение** и выбери папку `extension`.
5. Открой Pocket Tracker через иконку расширения.

## Подключение

Вставь целиком Socket.IO auth-сообщение из Pocket Option в формате `42["auth",{...}]`. Расширение проверяет событие `auth`, извлекает `sessionToken` и `uid`, сохраняет остальные поля и отправляет их брокеру, принудительно устанавливая `isDemo: 1`.

Не публикуй auth-сообщение: оно содержит действующий токен сессии. Если уже поделился им, выйди из Pocket Option и войди заново, чтобы обновить сессию.

Нажми «Подключиться к DEMO». Токен не сохраняется в chrome.storage и не выводится в журнал. Он находится только в памяти фонового процесса расширения. При перезапуске расширения потребуется ввести его снова.

Расширение подключается только к DEMO endpoints:
- `demo-api-eu.po.market`
- `try-demo-eu.po.market`

В авторизационный запрос принудительно передаётся `isDemo: 1`. Перед торговлей расширение ждёт ответ `successupdateBalance` и проверяет `isDemo` от сервера. Если DEMO не подтверждён, ручные и автоматические сделки заблокированы.

## Стратегия

- Свечи: 5 секунд, формируются из потока котировок.
- Bollinger Bands: 20 периодов, 2 стандартных отклонения.
- RSI: 14 периодов, сглаживание Wilder.
- PUT: закрытие у/выше верхней полосы (не дальше 1 point), RSI 77–83.
- CALL: закрытие у/ниже нижней полосы (не дальше 1 point), RSI 18–23.
- Экспирация: 15 секунд.
- Проверка выполняется только при закрытии свечи.

Для начала работы после подключения необходимо накопить не менее 20 закрытых свечей. Это занимает около 100 секунд.

## Важные ограничения

- Используется неофициальный Socket.IO протокол Pocket Option; брокер может изменить его в любой момент.
- Реализация пока не подтверждена тестовой сделкой на реальном аккаунте пользователя. Сначала проверяй только на DEMO.
- Если ответ на открытие ордера не пришёл за 12 секунд, расширение блокирует повторную отправку до ручной проверки истории сделок.
- Не вставляй SSID в публичные чаты и не передавай его третьим лицам. Если сессия скомпрометирована, выйди из аккаунта Pocket Option и создай новую сессию.
- Это не гарантия прибыльности и не инвестиционная рекомендация.

## Структура

- `manifest.json` — Manifest V3.
- `background.js` — DEMO WebSocket, поток котировок, стратегия и исполнение.
- `popup.html/js/css` — управление расширением.

## Разработка

Изменения протокола брокера могут потребовать обновления событий Socket.IO, форматов потока и payload ордера. Не снимай DEMO-проверку и fail-closed блокировки ради обхода ошибок.
