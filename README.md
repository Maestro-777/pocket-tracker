# Pocket Tracker

Локальный OTC-график для анализа котировок Pocket Option. Первая версия подключается к WebSocket Pocket Option в режиме чтения: загружает историю свечей и обновляет текущую свечу по потоку котировок.

> Важно: Pocket Option не публикует поддерживаемый публичный API. Подключение использует недокументированный WebSocket-интерфейс платформы, изученный по открытым сторонним реализациям. Он может измениться или перестать работать без предупреждения. Проект не связан с Pocket Option.

## Что уже есть

- Прямое WebSocket-подключение к региональным серверам Pocket Option.
- Авторизация через кадр сессии, который пользователь сам получает в браузере.
- Загрузка исторических свечей через \`loadHistoryPeriod\`.
- Обновление текущей свечи по событию \`updateStream\`.
- Инструменты: EUR/USD OTC, GBP/USD OTC, USD/JPY OTC, AUD/USD OTC и BTC/USD OTC; после авторизации список доступных инструментов может дополняться каталогом брокера.
- Таймфреймы 5с, 15с, 30с, 1м, 5м, 15м, 30м и 1ч.
- При подключении автоматически запрашивается история за последние 3 дня порциями по мере необходимости, только для выбранного инструмента и таймфрейма; при прокрутке история подгружается автоматически только в пределах трёхдневного окна.
- Поддерживается 5-секундный график; фактическая глубина истории зависит от того, сколько Pocket Option отдаёт для выбранного инструмента и таймфрейма.
- Горизонтальные уровни и линии тренда.
- Библиотека настраиваемых индикаторов: SMA, EMA, WMA, DEMA, Bollinger Bands, Keltner, Donchian, SuperTrend, Ichimoku, Parabolic SAR, RSI, MACD, Stochastic, CCI, Williams %R, ROC, AO, ATR, ADX/DMI, OBV, VWAP, MFI и Pivot Points.
- Избранное индикаторов и активные настройки сохраняются локально в браузере; параметры, цвет и толщина линий изменяются в окне настроек.
- Расчёт индикаторов вынесен в Web Worker и запускается с debounce, чтобы снизить нагрузку при обновлении потока.
- Проверка TLS-сертификатов использует системное хранилище и актуальный набор CA от certifi; проверка сертификата не отключается.
- Локальный мост: браузер обменивается данными только с \`127.0.0.1\`. Сессионный кадр не записывается на диск и не отправляется на GitHub.

Модуль графика по-прежнему только читает котировки. В отдельном торговом контуре добавлены детерминированный поиск сигналов по закрытым 5-секундным свечам и отправка команд `openOrder` через неофициальный Socket.IO-протокол Pocket Option. Исполнение fail-closed: разрешены только явно обозначенный DEMO в auth-кадре и дополнительное подтверждение DEMO событием `successupdateBalance`; REAL и неизвестный счёт блокируются. Открытие сделки считается успешным только после `successopenOrder`, отказ — после `failopenOrder`. При тайм-ауте состояние считается неопределённым, повторные ордера блокируются до синхронизации открытых сделок.

## Запуск на Windows

1. Установи Python 3.10 или новее.
2. Скачай репозиторий на компьютер или открой его локальную копию.
3. Запусти \`start.bat\`.
4. Дождись установки зависимости и запуска локального сервера.
5. Открой [http://127.0.0.1:8000](http://127.0.0.1:8000).

Можно запустить вручную из корня проекта:

\`\`\`bash
python -m pip install -r requirements.txt
python bridge.py
\`\`\`

После запуска открой [http://127.0.0.1:8000](http://127.0.0.1:8000). Не закрывай окно терминала, пока используешь график.

## Где взять кадр авторизации

1. Войди в свой аккаунт Pocket Option в браузере.
2. Открой инструменты разработчика клавишей F12.
3. Перейди во вкладку **Network** и включи фильтр **WS**.
4. Обнови страницу Pocket Option и выбери активное WebSocket-соединение с адресом вида \`wss://...po.market/socket.io/\`.
5. Открой вкладку **Messages** или **Frames**.
6. Найди исходящее сообщение, которое начинается с \`42["auth",\`.
7. Скопируй весь кадр целиком и вставь его в поле подключения Pocket Tracker.

**Никогда не отправляй этот кадр в чат, не публикуй его и не добавляй в файлы репозитория.** В нём находится сессионный токен, который следует считать паролем. В интерфейсе поле очищается сразу после отправки, а локальный мост держит данные только в оперативной памяти до отключения.

Начинай проверку с демо-счёта. Для прекращения соединения нажми **Отключить** или закрой локальный мост.

## Архитектура

- \`web/\` — интерфейс на Lightweight Charts.
- \`bridge.py\` — локальный HTTP-сервер интерфейса и WebSocket-мост к Pocket Option.
- \`requirements.txt\` — Python-зависимости.

Локальный HTTP-интерфейс слушает только \`127.0.0.1:8000\`, мост — только \`127.0.0.1:8765\`. Сессионные данные не сохраняются в настройках браузера, файлах или логах приложения.

## Сигнальная стратегия и расширение браузера

Торговый движок находится в `strategy.py` и работает внутри `bridge.py`, независимо от графика:

- Bollinger Bands: период 20, множитель 2, источник Close.
- RSI Уайлдера: период 14, источник Close.
- Расстояние закрытия свечи до Upper не больше одного минимального шага цены и RSI 77–83 → PUT.
- Расстояние закрытия свечи до Lower не больше одного минимального шага цены и RSI 18–23 → CALL.
- Анализ выполняется только после перехода к следующей 5-секундной свече; одна свеча не создаёт повторных сигналов.
- Экспирация — 15 секунд.
- Точность шага цены берётся из каталога активов брокера, если сервер передал число знаков.

Расширение Chrome/Edge v1.3.0 показывает сигналы, содержит ручные кнопки CALL/BUY и PUT/SELL, сумму сделки и переключатель автоторговли. Команды идут через открытую вкладку локального Pocket Tracker в существующее соединение моста; расширение не перехватывает WebSocket графика Pocket Option.

**Ограничения и риски:** Pocket Option не предоставляет публичную документированную торговую API; торговый контур использует неофициальные внутренние события, которые могут измениться. Реальные сделки не поддерживаются: только DEMO после серверного подтверждения. Для исполнения нужны открытый локальный Pocket Tracker, активное соединение моста, 5-секундный период и доступный инструмент из каталога брокера.

Установка расширения: открой `chrome://extensions` или `edge://extensions`, включи режим разработчика и загрузи распакованную папку `extension/`. Полная инструкция находится в `extension/README.md`.

## Известные ограничения первой версии

- WebSocket-интерфейс неофициальный; адреса региональных серверов и формат сообщений могут измениться.
- Сессионный кадр может истечь или быть отклонён сервером.
- Список таймфреймов и инструментов зависит от того, что сервер Pocket Option разрешает конкретной сессии.
- Формат исторических данных может отличаться между инструментами и версиями платформы. Если история не появляется, но соединение установлено, это нужно уточнить по фактическим кадрам сервера.
- График не следует считать источником торговой гарантии или сигналом к сделке.

## Следующий этап

После проверки соединения можно расширить набор инструментов: RSI, MACD, Bollinger Bands, уровни/зоны, алерты и визуальный конструктор условий для сигнального бота. Бот должен использовать тот же нормализованный поток свечей, что и график.
