# Pocket Tracker 4.0.0

Новая ветка расширения на основе проверенной структуры 3.6.0. Сохранены существующие модули анализа, сигналов, журнала и автоматического нажатия торговых кнопок; панель переработана в стиле отдельного окна 3.6.0.

## Новое в 4.0.0
- Обновлённая панель управления в отдельном окне.
- Полностью убраны вкладка «Контакты», интеграция маркета пресетов и связанный с ней мост; встроенные пресеты стратегий остаются доступны.
- Удалено необязательное разрешение на доступ ко всем сайтам.
- Ширина панели на странице и отдельного окна увеличена на 2 пикселя.
- Автоопределение DEMO/REAL по явным событиям страницы, URL и видимым атрибутам/меткам.
- Отображение статуса счёта на странице и в панели.
- Запуск из отдельной панели блокируется, если тип счёта неизвестен; REAL требует дополнительного подтверждения.
- При недостатке достоверных признаков режим остаётся «не определён».
- Детектор работает только в главном фрейме, не использует глобальный MutationObserver и не опрашивает DOM в цикле.

## Мульти-парная торговля (перенесено по модели 1.1.7_0)
- Режим сканирует каталог Pocket Option и выбирает активные валютные пары с доходностью не ниже заданного порога; по умолчанию — 92%.
- Включение OTC-пар настраивается отдельно и по умолчанию включено.
- Поток котировок подписывается отдельно для каждой подходящей пары; анализ выполняется по данным каждой пары, а не только по открытому графику.
- При сигнале ордер отправляется для соответствующего символа. Повторный вход по паре блокируется, пока предыдущая сделка по ней не закрыта.
- Общий лимит одновременно открытых/ожидающих сделок — 4 по умолчанию; настройка доступна в диапазоне 1–20.
- В мульти-парном режиме используется фиксированная базовая ставка. Прогрессивные схемы Money Management не применяются, чтобы результаты параллельных сделок не меняли общую последовательность ставок.
- Результаты сделок по разным валютным парам записываются в журнал отдельно.
- Настройка REVERS выключена по умолчанию; при включении после заданной серии побед (по умолчанию 3) бот начинает открывать сделки против направления сигнала.
- Порог REVERS настраивается ползунком от 1 до 10 побед. Следующая такая же серия побед переключает режим обратно; проигрыш или возврат ставки сбрасывает счётчик текущей серии.
- Счётчик серии и режим REVERS действуют в рамках текущего запуска бота и сбрасываются при новом запуске.


## Strategy Lab: сравнение 20 вариантов на истории

В настройках панели добавлена «Лаборатория стратегий». Она сравнивает 20 комбинаций EMA, MACD и Trend: четыре набора периодов (Fast, Quick, Balanced, Slow) × пять логик (все три фильтра, три пары фильтров и голосование 2 из 3).

- Таймфрейм анализа задаётся отдельно от экспирации. Для экспирации 60 секунд можно выбрать S15 (четыре свечных интервала на сделку).
- Тест запускается только для выбранного OTC-актива и использует сохранённые исторические OHLC-свечи Pocket Option. Если данных мало, расширение запрашивает историю; синтетические свечи из текущих тиков не подменяют исторический OHLC.
- Первые 70% хронологической истории используются для ранжирования стратегий. Последние 30% отображаются отдельно как out-of-sample (OOS) проверка и не влияют на сортировку.
- Сигнал рассчитывается только по закрытым свечам. Модель сделки: вход по open следующей свечи, выход по close свечи, которая завершает заданное число полных интервалов. Тест пропускает окна с пропущенными свечами.
- Выплата задаётся пользователем (по умолчанию 92%). В отчёте есть win rate без DRAW, expectancy на одну разрешившуюся сделку и нижняя 95% граница Уилсона. Для предварительного ранжирования требуется не менее 20 разрешившихся TRAIN-сделок; OOS помечается малым, если там меньше 50 разрешившихся сделок.

Это исследовательский инструмент, а не генератор гарантированной доходности. OHLC-бэктест не воспроизводит точную задержку исполнения, тики на границе экспирации, возможное проскальзывание и изменение выплаты. Даже хороший OOS-результат требует дальнейшей проверки на новых данных и демосчёте.

### Тесты
Из корня репозитория:
- `node Pocket-auto/tests/indicators.test.js`
- `node Pocket-auto/tests/strategy-lab.test.js`

Второй тест проверяет, в частности, что изменение только отложенной части истории не меняет TRAIN-метрики и ранжирование.

## Установка для разработки
1. Откройте `chrome://extensions`.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку `4.0.0_0`.
4. Откройте Pocket Option и проверьте распознавание на DEMO, затем на REAL.

## Важное ограничение
Pocket Option может менять DOM, URL и внутренние WebSocket-события. Детектор намеренно не угадывает REAL по отсутствию DEMO: при недостатке признаков он показывает «не определён». Перед использованием автоторговли необходимо отдельно проверить распознавание на актуальном интерфейсе и убедиться, что тип счёта совпадает с фактическим. Никакая стратегия не гарантирует прибыль.

## Исправление зависания страницы
В ранней сборке детектор следил за всем DOM и при каждом изменении перезаписывал текст бейджа, который сам же создавал новые DOM-изменения. Это могло вызывать бесконечный цикл MutationObserver и блокировать интерфейс сайта. Исправлено: глобальный наблюдатель и периодический опрос удалены, отрисовка выполняется только при изменении состояния, а скрипт запускается только в главном фрейме.
