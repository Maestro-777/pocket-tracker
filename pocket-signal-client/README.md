# Pocket Signal Client (MVP)

Минимальное отдельное расширение Chrome/Chromium для ручного запроса сигнала у SignalBots.

## Что делает
- Отправляет GET-запрос на SignalBots signal endpoint из background service worker.
- Передаёт broker=pocket-option, mode=real, выбранные pair и tf, salt=0 и item=ext-pocket-option.
- Использует cookies текущего браузера для signalbots.ai (credentials: include).
- Позволяет передать лицензионный ключ в поле интерфейса.
- Показывает направление, если оно присутствует в ответе, и полный JSON сервера.

## Чего не делает
- Не подключается к Pocket Option.
- Не читает котировки и не рассчитывает сигналы локально.
- Не размещает сделки и не содержит автоматической торговли.
- Не обходит авторизацию, лицензию или ограничения SignalBots.

## Установка для теста
1. Откройте chrome://extensions.
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение».
4. Выберите папку pocket-signal-client из репозитория.

## Первичная проверка
1. При необходимости сначала войдите на https://signalbots.ai в том же браузере.
2. Выберите EURUSD и 1 мин.
3. Нажмите «Получить сигнал».
4. Если запрос отклонён, сохраните HTTP-статус и JSON из раскрывающегося блока. Это покажет, требует ли endpoint дополнительную авторизацию, лицензию или параметры.
